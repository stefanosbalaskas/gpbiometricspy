# Security and private-data guidance

Do not commit private participant exports, identifiers, credentials, device serials or generated private smoke-test outputs to this repository.

The package contains synthetic public demo data only. Real-data smoke helpers are designed to produce aggregate/readiness outputs and include privacy audits, but users remain responsible for institutional data-governance requirements and de-identification.

Report software vulnerabilities through the repository's private security reporting channel when available rather than opening an issue containing sensitive data.
